# Uzbek Motivation Telegram Bot

Telegram bot that provides Uzbek motivational messages, quotes, daily humor, and poetic lines, with a random daily broadcast to active users.

## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server (port 5000)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- Required env: `DATABASE_URL` — Postgres connection string
- `python main.py` — run the Telegram bot
- Required secret: `TELEGRAMTOKEN`
- Optional secret: `GEMINI_API_KEY` (Gemini content generation; local Uzbek content is used if unavailable)

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- API: Express 5
- DB: PostgreSQL + Drizzle ORM
- Validation: Zod (`zod/v4`), `drizzle-zod`
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)

## Where things live

- `main.py` — Telegram handlers, Gemini/local content routing, scheduler, and JSON storage
- `gemini_content.py` — bounded, retrying Gemini text generation for Uzbek bot content
- `local_quotes.py` — offline Uzbek quote combinations for every mood
- `extended_content.py` — offline quote, humor, and poetic-line content bank
- `data/users.json` — runtime user records (created automatically and ignored by git)
- `README.md` — setup and command reference

## Architecture decisions

- Gemini generates mood replies, humor, poetry, and daily messages. Quotes are selected only from the sourced local collection; the bot shows each author and work and links to the source.
- Gemini API usage is billed by Google separately from consumer Gemini subscriptions; keep API usage and billing limits in mind.
- APScheduler's `AsyncIOScheduler` runs in the Telegram application's event loop.
- User records are stored in an atomically replaced JSON file to avoid partial writes.
- Default scheduling timezone is `Asia/Tashkent`, configurable via `BOT_TIMEZONE`.

## Product

Users select one of 12 mood categories and receive a short, practical motivational message in Uzbek. Active subscribers receive a fresh daily message at 07:00.
The bot profile describes its daily unique quote, humor, or poetic-line content.

## User preferences

Messages should use simple Uzbek Latin, feel warm and hopeful without forced positivity, and follow the selected content type. Humor should be only a short joke, without an added motivational paragraph. Messages may draw on broad ideas associated with respected thinkers, scientists, psychologists, and well-known books, but must be original, not copied or closely paraphrased, and must not invent attributions or scientific claims.
Quote responses must come from a sourced local collection, not be generated by AI.

## Gotchas

- Never put bot tokens or API keys in source files or logs.
- Run the bot as a long-lived process; APScheduler broadcasts only while the process is running.
